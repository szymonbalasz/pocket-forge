# Rulings: phase 1b spec review

Integrator rulings on the two review reports (review-data, review-ui-provider). Spec authors apply these in the revision round. Where a ruling conflicts with older spec text, **the ruling wins**. Product calls are in [gate-phase1b.md](gate-phase1b.md), not here. **Accepted by the owner (#40).** Gate decisions that also apply: #37 (capability-driven controls are tier S), #39 (simple conflict resolution).

| # | Topic | Ruling | Specs |
|---|---|---|---|
| R1 | **Region and mask size** (blocker) | **Region** = the inner rect. **Context margin** = the margin around it. Outer rect = region + context margin. EDT submits an inner-rect mask. RGN pads it with 0 to the outer rect, resamples it by the fit scale, then validates it. PRV converts polarity only. Each overlay row states `soft: pass-through \| threshold(128)`. Alpha-convention masks carry the source RGB. | EDT, RGN, PRV, glossary |
| R2 | **Job record** (blocker) | One field table in the new `docs/architecture/manifest-schema.md` (PRJ owns it). States: `requested` (no handle) → `submitted` (handle) → `queued` → `running` → `succeeded` → `fetched` → `closed`, plus `failed`, `canceled`, `unknown`, `lost`. Terminal = `failed \| canceled \| lost \| closed`. Every exit is drawn. Persist state on every transition (drop "≤ 3"). Layout: `jobs/<id>/job.json` + `region.png` + `mask.png`, stored as sent (after fit, before polarity conversion). Fields: `fit`, `region{inner,outer,margin}`, an opaque `provider{}` (PRV owns its inner shape). The job file is authoritative; manifest `jobs[]` is an index rebuilt on open. A crash before the handle is saved → `lost`. | PRJ, RGN, PRV |
| R3 | **Undo of accept** (blocker) | Undo of accept or re-tune = `project_restore_revision(parent)`, reason `restore`. Redo = restore the later revision. A re-tune makes a **new layer id and file** plus a `retune` revision. Revisions get an optional `label`. Glossary: Revision = "a saved state". | PRJ, EDT, RGN, EXP |
| R4 | One command per capability | RGN owns the user-facing job and candidate commands (`rgn_*`). PRV owns `provider_list_models` / `provider_get_capabilities` (RGN drops its copies). PRJ exposes only a store API, extended with `update_job`, `discard_candidate`, `replace_patch_layer`, `put_export`, `settings_get/put`. Accept plus trashing the rest = one commit. EDT commands get the `edt_` prefix. | all |
| R5 | Tile cache | EDT owns key, cap (**2 GiB**), eviction and path (`<data-dir>/cache/tiles/…`). FR-PRJ-38 becomes a pointer to EDT. | PRJ, EDT |
| R6 | What export composes | The **current** manifest layer stack. Record `last.revision_id` + `last.layers_hash`. `last.path` is relative to the project folder. Settings commit at `export_start` (no per-keystroke commits). Display size needs both px-per-square values. | EXP, PRJ, EDT |
| R7 | Draft mask | `edt_mask_submit` runs on stroke-end debounce (≥ 2 s) and on job submit. The draft points at the latest mask. Superseded masks that no job or revision references go to the trash at the next commit. | EDT, PRJ |
| R8 | Settings | PRJ owns `<data-dir>/settings.json` with sections `library`, `spend`, `provider`. Atomic write; a corrupt file → defaults plus a warning. PRJ lists every file in `<data-dir>`. Reword FR-PRJ-37: caches are rebuildable; settings are per-machine config. | PRJ, RGN, PRV |
| R9 | Retention of job inputs | Inputs of jobs that end with nothing accepted or starred go to the trash with their candidates (#18). Accepted jobs keep them forever (KQ-17). | PRJ, RGN |
| R10 | Candidate record | `candidates/<id>.<ext sniffed>`, with `index`, `provider_meta` (opaque), status `new \| accepted \| dismissed \| discarded \| trashed \| invalid`, and `starred` as a separate flag. UI statuses: `pending \| ready \| invalid`. | PRJ, RGN, EDT |
| R11 | Decoded original | PRJ owns a `DecodedOriginal` handle, loaded lazily on the first RGN or EXP use, prefetched when the region tool is picked, and released on close. Add a whole-app memory line for 16k. Until it's ready, RGN and EXP return `original_unavailable`. | PRJ, RGN, EXP |
| R12 | Errors, read-only, conflicts | PRJ's codes everywhere (`locked`, `conflict`, `read_only`). A pending-write spool in `<data-dir>/pending/<project_id>/` holds candidate bytes and job updates during a conflict, replayed after it's resolved. In a read-only project you can view and paint; everything that writes fails fast with `read_only` and submit is disabled. | PRJ, RGN, EDT |
| R13 | OneDrive testability | A filesystem-attributes seam (`is_cloud_only`, `hydrate`) with a fake in tests, plus a manual OneDrive check in the walkthrough. | PRJ |
| R14 | Poll loop | RGN's job runner owns the loop and persistence, using PRV's `status` + `poll_delay`. Polling continues until the job is terminal, even if its project is closed while the app stays open. Fix RGN §4 and §10. | RGN, PRV |
| R15 | Uploads | PRV owns them: at most once per content hash per session, with cached refs. Estimate only when a cost-affecting input changes. If a dry run doesn't need the image assets, skip upload until submit (verify in the build). | PRV, RGN |
| R16 | Preview and thumbnails | EDT adds a transient registered-key path (`/i/<key>`) through a core fn, so RGN returns `{key, rect}`. Thumbnails come from an `edt_image_open` `max_side` variant. | EDT, RGN |
| R17 | Fake provider cases | PRV adds `bad_candidate`, `aspect_mismatch(pct)`, `offset(levels)`, `canceled` and `slow`, and RGN uses those names. Recordings are Scenario replay only. | PRV, RGN |
| R18 | Region tool | EDT owns the pointer tool (`R`, `edt-toolbar-region`, drag/move/resize) and emits `{inner}`. RGN validates it through `rgn_region_fit`. OQ-EDT-03 closes (= OQ-RGN-01 A). | EDT, RGN |
| R19 | Picker API | `onSelect` / `onAccept` / `onStar` / `onDiscard`, with `edt-picker-*` test ids only. | EDT, RGN |
| R20 | Input-limit errors | RGN pre-checks with `input_too_large`; PRV backstops. PRV exposes `input_px{min,max,multiple_of}` in capabilities. Estimate lists every normalised error. | RGN, PRV |
| R21 | Naming | Events `<area>:<kebab>`, errors `snake_case`, test ids per §9 with an area segment. | all |
| R22 | §9 additions | `PF_FAULT` and `PF_FAKE_NOW` (test builds only). Walkthroughs set both `PF_DATA_DIR` and `PF_LIBRARY_DIR`. | §9 (orchestrator) |
| R23 | Editor details | Display size uses CSS px. Shortcuts are ignored while a text field has focus. DPR changes are asserted on the next frame. | EDT |
| R24 | Revisions | Reasons add `retune`. `r0…` in walkthroughs are display labels for `seq`. | PRJ, RGN |
| R25 | Seam check | Walkthroughs use FR-RGN-32's metric on the exported file instead of "looks seamless". | EXP |
| R26 | Length | Schema tables move to `manifest-schema.md`. Short appendices are allowed for the URI grammar, recording format and overlay rows. Target ≤ 150 lines of main text. | all |
| R27 | Glossary batch | Add: Manifest, Draft, Estimate, Flatten, Context margin, Job handle, Trash, Conflict copy, Local cache, Px per square, Display size, Colour match, Spend cap, Fake provider, Mask convention, Model overlay, Re-tune. Redefine Region and Revision. Note: the tier-S "feather" = the patch blend feather; brush softness = "hardness". | glossary (orchestrator) |
| R28 | Control roles (OQ-RGN-14) | PRV's `controls[]` gets a `role` field: `source \| mask \| prompt \| candidate_count \| seed \| reference \| other`, from the overlay where Scenario doesn't say. RGN binds the source, mask and prompt by role, never by input name. | PRV, RGN |
| R29 | Glossary (OQ-PRV-21, OQ-PRJ-12) | Added Provider asset ref, Balance, Head revision, Import destination, Spool. | glossary (done) |
| R30 | Export settings persistence (OQ-EXP-11) | Typed export settings (px per square values, format) persist through PRJ's debounced draft save (≥ 2 s), not per keystroke and not only at `export_start`. Display size survives close/reopen. Amends R6. | EXP, PRJ |
| R31 | Consistency leftovers | (1) R30 settings live in the manifest `export` record (no new field). (2) OQ-PRV-22 = A; drop `has_handle()`. (3) Errors: `unknown_id` for unknown ids, `not_found` for paths. (4) Spell `canceled` everywhere. (5) Accept ~3.3 GiB peak for a 16k export with resize (16k is the upper bound, #30); a region job and an export share the one decoded original, and export start is refused with `busy` while a job is fetching/baking. (6) `slots[]` is derived from controls with `role: reference` (no duplicate naming). (7) Glossary adds Read-only, Job runner, Capability snapshot, Session spend. (8) editor-canvas depends on export. | all |
| R32 | Re-pick (OQ-RGN-13 = B, #41) | The job stays `closed` (R2 unchanged). When the newest job's accept is undone, its candidates can be accepted again; `accept_candidate` restores a trashed file in the same commit. Not after a newer job or the 30-day purge (`repick_unavailable`). | RGN, PRJ, schema |
| R33 | Corrupt images (skeleton walkthrough) | Import runs a cheap end-of-file check; open refuses an image that fails to decode (PRJ slice 3). No full decode on import (16k is slow). | PRJ |
| R34 | Original layer fields | `region`, `rect`, `blend` and `retune_of` are patch-only in schema §4.3; the original layer omits them. | schema |
| R35 | Temp-file sweep | The open-time sweep also removes orphan temp files in the library import folder and `<data-dir>` (PRJ slice 5). | PRJ |
| R36 | CSP | A strict Content Security Policy lands with EDT slice 1 (the `pf-tiles` scheme), not before. | EDT |
| R37 | Branch updates | Builders merge `origin/main` into their branch instead of force-pushing a rebase (no history rewrites; a safety hook blocks force pushes anyway). | all builders |
| R38 | pf-imaging build | `unsafe_code = "deny"` in pf-imaging (only `webp.rs` allows it, for libwebp FFI); the workspace keeps `forbid`. `jpeg-encoder` with `simd`. Lossless WebP fallback at level 1. Dev profile builds pf-imaging at `opt-level = 2`. `rayon` is in workspace deps, unused until a builder needs it. | EXP, EDT |
| R39 | Region fit fallback | EDT's local `rgn_region_fit` fallback is removed when RGN's command lands. | EDT, RGN |
| R40 | Provider build calls | `required.ifDefined/ifNotDefined` stay a warning (control optional) until a recorded model uses them. Offline `status` = `unknown` + `error: offline`. pf-provider deps stay in its own Cargo.toml. The Windows CI job runs the FR-PRV-06 OS-store test. The duplicate `prv-status-mode` rail chip is removed by the PRJ UI builder. | PRV, PRJ |
| R41 | Focus after a mouse click | Toolbar, view-preset and picker buttons don't keep focus after a mouse click, so Space-to-pan works right after picking a tool. Tab focus is unchanged and gets Enter/Space first (#48). | EDT |
| R42 | Region-edit core calls | An empty prompt estimates with a placeholder (cost doesn't depend on it). `scale` = sent ÷ outer on the longest side. The estimate also returns `fit`, `candidate_count`, `threshold`, `over_cap`; in `rgn_spend_set` a missing field keeps its value and `null` clears it. Hidden-control values are dropped; source/mask/prompt/seed roles inside `controls` are rejected (`bound_by_role`); a default outside a narrowed set falls back to the first allowed value. Estimates are refused in a read-only project. | RGN |
| R43 | Export command shapes (for slice 3) | Inputs nested `{settings}` / `{settings, replace}`. `export_plan.path` is project-relative (`exports/…`, like `last.path`); `export:done.path` is absolute. `project_prefetch_original` re-emits `project:original-ready` when already decoded. `invalid_settings` detail = `{field, detail:{limit:{min\|max\|requires}}}`. The status bar wraps and hides empty segments. Export renders under Generate: RGN's right-slot entry precedes `exportFeature` in `features.ts`. | EXP, PRJ, RGN |
| R44 | Region-edit UI calls | `rgn_candidate_preview` returns `url` too (the UI never builds hosts, EDT App. A). A feature may import another feature's `index.ts` (ESLint rule fixed, §9). EDT exposes a read-only `useEditorRegion()`. | RGN, PRJ, EDT |
| R45 | Asset-project core calls | Core and UI merge together. `SkipReason` adds `not_available_offline`; cards allow `last_edited: null`. Discarding a starred candidate clears its star; leading dots are trimmed from names; `update_job` refuses `fetched`/`closed` (store-owned). RGN moves from `original_path()` onto `decoded_original`. | PRJ, EDT, RGN |
| R46 | BL-07 smoke tile check | CDP can't be enabled on the CI runner's WebView2, so the check runs **in-app**: in debug builds with `PF_SMOKE`, the UI opens `PF_SMOKE_TILE_IMAGE` through the core, fetches tile `0/0_0` and reports the result in `app_ready`. | R47 | Region-edit jobs shared-file edits | Confirmed (additive): `error.rs` + `invalid_candidate`, `source_missing`; `job.rs` + `references[]`; `store.rs` `NewJob{references, extra}`, `NewCandidate{extra}`; `manifest.rs` `Draft.references`, `DraftInput.references`; the resume hook in `project_open`; the runner pump thread spawned in Tauri `lib.rs`.
